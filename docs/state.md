# State Engine

## Ziel

Die State Engine analysiert ein Softwareprojekt und erzeugt einen strukturierten Zustand ("State").

---

## Eingaben

- project_path
- task

---

## Ausgaben

- Projektname
- Programmiersprache
- Framework
- Aufgabenklassifikation
- relevante Dateien
- Beobachtungen
- Annahmen

---

## Verantwortlichkeiten

Die State Engine ist verantwortlich für:

- Analyse der Projektstruktur
- Erkennung der Programmiersprache
- Erkennung des Frameworks
- Klassifikation der Aufgabe
- Ermittlung relevanter Dateien
- Erzeugung eines strukturierten State-Objekts

---

## Nicht verantwortlich

Die State Engine darf **nicht**:

- Erfahrungen abrufen
- Lösungen erzeugen
- Entscheidungen treffen
- Vorhersagen berechnen
- Lernen

Diese Aufgaben übernehmen andere Module.
